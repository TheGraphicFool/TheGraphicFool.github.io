This is a starter post so the blog isn't empty. Replace it, or delete
`content/blog/hello-world.md` and `public/blog/hello-world.svg` once you've
published your own.

## How to publish a post

1. Run `npm run new-post -- "Your title"`, or copy this file in `content/blog/`.
   The file name becomes the URL: `my-post.md` → `/blog/my-post`.
2. Put the cover image in `public/blog/` and point `cover:` at it.
3. Push to `main`. The site rebuilds and the post goes live in about a minute.

A post can be **just a cover image** — leave everything below the second
`---` empty.
